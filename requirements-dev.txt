# ruff / mypy は上限を切って固定する。
# どちらも「新しい版で検査が厳しくなる」種類のツールで、上限なしにすると CI は毎回
# 最新版を取りに行くため、コードを 1 行も触っていない PR が、上流のルール追加だけで
# 突然赤くなる（＝失敗の原因が差分の中に無い状態になる）。
# 上限を切っておけば更新は Dependabot の PR として届き、新ルールへの追随を
# 独立した 1 コミットとしてレビューできる（§9「依存を管理する」）。
# ruff は 1.0 未満で、マイナー更新（0.14 → 0.15）に選択カテゴリへの新ルール追加が入るため
# マイナー単位で、mypy は semver に従うためメジャー単位で上限を置く。
ruff>=0.14.0,<0.15.0
mypy>=1.18.0,<2.0.0
